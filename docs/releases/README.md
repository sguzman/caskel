# Historical upstream Kiri release notes

The versioned notes in this directory are inherited from
[libracoder/kiri](https://github.com/libracoder/kiri), before or outside
the Linux-first Caskel product. They are preserved as upstream historical
reference and attribution, **not** Caskel release claims, update feeds,
support commitments, or evidence of Caskel feature verification.

The [guest-kernel provenance ledger](../kernel-provenance.md) records
upstream published source-archive metadata without claiming complete
archive verification or representing inherited tags as Caskel releases.

For this project's actual tested features and release process, see
[features](../features.md), [releases](../../RELEASES.md) and the
[verification ledger](../roadmap.md). Do not link users to Kiri's private
download service as a source of Caskel binaries.
