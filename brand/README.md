# Caskel visual identity

This is an **original** Caskel identity: a green C-shaped container bracket
with three internal stack lines on a charcoal rounded tile. It is not the
upstream Kiri mascot, logo or copyrighted icon set.

- Primary green: `#54D7AA`
- Tile background: `#14232D`
- Foreground detail: `#EAF9F4`
- Primary wordmark for light backgrounds: `caskel-wordmark.svg`
- Light-on-dark wordmark: `caskel-wordmark-dark.svg`
- Standalone icon: `caskel-mark.svg`

All assets are source SVG, editable and scalable. The GTK window uses the
same mark where the host's SVG pixbuf loader is installed, with a system
application icon fallback. Current headless Nix packaging does not ship
a GTK desktop entry; do not infer that a GUI package is verified.

Historical Kiri source attribution stays in the Apache-2.0 LICENSE/NOTICE
and corresponding-source records, never in Caskel's primary logo.
